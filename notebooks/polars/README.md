# Polars Notebook Split

These notebooks are the smaller polars-focused analysis parts. Each notebook repeats the setup cells it needs so you can run it independently.

- `01_data_prep_and_core_relationships.ipynb`: loading, merge, per-capita features, early relationship plots
- `02_income_groups_and_carbon_efficiency.ipynb`: income groups, efficiency, and outlier analysis
- `03_electricity_mix_and_energy_use.ipynb`: electricity shares and energy-use analysis
- `04_clustering_and_dimensionality_reduction.ipynb`: clustering, UMAP, PCA, and cluster interpretation
